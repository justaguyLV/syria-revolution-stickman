# الثورة السورية بالستيكمان والخرائط

فيديو تاريخي (~4.5 دقيقة) يُبنى بالكامل داخل **GitHub Actions**:

| المرحلة | الأداة |
|---|---|
| السيناريو | `data/scenes.json` (تعليق عربي + مشاهد + علامات الخريطة) |
| الصوت | `edge-tts` (ar-SA-HamedNeural) + موسيقى خلفية بـ ffmpeg |
| الخرائط | تضاريس حقيقية (AWS Terrarium) مظلَّلة بالـ hillshade + حدود المحافظات والمناطق الفعلية (geoBoundaries) + مناطق سيطرة تقريبية على مستوى المنطقة الإدارية (shapely) |
| الرسم | ستيكمان بهيكل عظمي كامل (`src/rig.py`): مفاصل، وجوه معبّرة، أعلام، لافتات، بنادق، سقوط وهروب + نص عربي بـ libraqm |
| المؤثرات | `src/fx.py`: وميض فوهات، انفجارات ودخان على الخريطة وعلى المشهد، اهتزاز، ألعاب نارية، فقاعات هتاف |
| الأصوات | `src/sfx.py` (توليد برمجي): رصاص، قذائف، طائرات، صفارات، زلزال، تصفيق، احتفالات + هتافات حشود بأصوات TTS متعددة. الجدول في `data/sfx.json` |
| المونتاج | ffmpeg (x264 + aac) |

## التشغيل
Actions → **Build Syria Revolution Video** → Run workflow. الناتج في Artifacts وفي Releases.

محليًا: `pip install -r requirements.txt && python src/build.py`
(بدون إنترنت للصوت: `NO_TTS=1` يعطي صوتًا صامتًا للاختبار، و`--preview spark,isis` يصدّر صور معاينة).

## ملاحظات حول الدقة
- خرائط السيطرة **توضيحية تقريبية** وليست حدودًا دقيقة.
- أرقام الضحايا تقديرات؛ الرقم المعروض (306,887) تقدير مفوضية الأمم المتحدة لحقوق الإنسان للمدنيين 2011–2021.
- المصادر: OHCHR، CRS، مجلس الأمن، EUAA، المجلس الأطلسي، MEI.
- لتعديل أي معلومة غيّر `data/scenes.json` وادفع، ويُعاد البناء تلقائيًا.
